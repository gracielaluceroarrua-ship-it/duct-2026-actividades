# Actividad Integradora - Módulo 4

Script en Python diseñado para realizar un análisis de frecuencia de palabras a partir de un archivo de texto plano, unificando criterios de mayúsculas/minúsculas y generando una visualización gráfica de los resultados.

## Características principales
- Lectura segura de archivos mediante control de excepciones (`try/except`).
- Conteo eficiente de frecuencias utilizando estructuras nativas.
- Visualización automatizada del Top 10 de palabras mediante `matplotlib`.
- Pruebas unitarias robustas implementadas con `pytest`.

## Instrucciones de ejecución
1. Asegurarse de colocar el archivo de texto a analizar (`texto_integradora.txt`) en la misma carpeta del script.
2. Ejecutar el programa principal con el siguiente comando en la terminal:
   ```bash
   python analizador.py
